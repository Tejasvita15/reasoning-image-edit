# RQ1 Step1X K-small multi-seed outputs

This package contains 40 frozen K-small examples, each with Thinking and Thinking + Correction outputs for seeds 42, 1234 and 7 (240 edited images total).

The source and available reference images come from KRIS-Bench and were re-encoded as PNG without resizing.

The manifest contains condition and seed assignments. Do not show this manifest or labelled output paths to a blinded evaluator. Prepare blinded batches before Astra Pro judging.

This package is separate from the 10-example calibration study.
