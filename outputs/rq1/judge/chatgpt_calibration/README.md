# RQ1 Step1X manual ChatGPT UI calibration

**Never upload this README, the ZIP as a whole, or private/ to the judging chat.** The private manifest reveals condition assignments.

Use a fresh GPT-6 Astra Pro chat for **each** upload/pass_N/pN_bNNN batch. Attach all images in the batch with original filenames and paste that batch's prompt.md. Do not supply conditions, seeds, original generation prompts, or prior scores.

Two independent passes must use new chats; pass 2 must not see pass-1 responses. Save each verbatim JSON response in responses/p1_b001.json etc, and preserve session URLs/actual model/UI mode/dates separately for provenance.

This is a UI adaptation and not directly identical to the pinned GPT-4o API judge. The rubrics come from this repository's official KRIS evaluator prompts; some contextual differences remain (combined metrics and visible batch images).
The RQ1 final images are K-test seed 42 and only 10 selected K-small examples for calibration; this is NOT the full multi-seed evaluation.
